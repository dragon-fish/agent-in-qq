# Codex 群聊权限

## 目标

让群聊里的 Codex 在工作区内直接做日常开发，需要额外权限时由 Codex 自动审核，减少切去私聊点审批卡的次数。

## 权限行为

- 群聊默认使用 `workspace-write`。该模式将 `on-request` 请求交给 App Server 的 `auto_review`，保留原有工作区和网络边界。
- 主人可在任意群单独执行 `/mode full`（`danger-full-access`）或从菜单选择完整访问。选择按群保存，重启后生效。完整访问使用本机账号的文件和网络权限，群里的其他 op 仍可启动该群的回合。
- 群聊的完整访问只接受主人通过该群的 `/mode` 显式设置。进程级 `QQ_PERMISSION_MODE` 的完整访问设置不影响群聊。
- 私聊、只读和完整访问继续使用现有人工审批策略。Codex 在完整访问下仍可能为独立工具权限请求审批。

## 验收

- 同一进程里的群聊工作区模式用自动审批，私聊工作区模式用人工审批。
- 主人能给普通群和信任群单独开启 Full。其他 op 无法用命令或菜单开启 Full。
- 已保存的 Full 在重启后恢复。另一个群仍使用工作区模式，进程级 Full 不会给任何新群开启完整访问。
