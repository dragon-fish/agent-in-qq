# 直接消息的附件：内联图片 + 附件块

## 目标

私聊里的图片只内联、不给原始链接，agent 拿不到原文件；群里 @ 的图片只给链接，agent 要多一轮下载才能看到。两种直接消息统一成同一种形态。

## 范围

- 包括：私聊消息、群里唤醒 agent 的消息（@、引用、昵称）、私聊里对 `qq_ask` 的文字回答。
- 不包括：群历史（`qq_group_history` 和 `recent`）只给链接、不内联。

## 决定

1. 直接消息带附件时，图片下载后内联给 agent，同时在 `</user_message>` 后附 `<attachments>` 块，列出全部附件（文件名、下载链接、类型）。
   Why：只有图片能内联，zip、音频之类只能靠链接；内联省去 agent 下载看图的一轮，链接留给需要原文件的场合。
2. 内联成功的条目带 `"inlined": true`，内联图片的顺序与这些条目一致；下载失败的图片不标，agent 自己去拿。
   Why：让 agent 知道看到的图就是块里的哪一项，不误以为是两份不同的图。
3. 私聊不再在正文里追加 `[文件] 名字 链接` 这类注记，附件信息只出现在附件块里。
   Why：一份信息一个出处。
4. 私聊与群聊的附件统一解析成同一种结构（文件名、链接、可选 MIME），没有链接的条目丢弃。
5. `qq_ask` 的文字回答带附件时，回答文本后面同样附上 `<attachments>` 块，图片同样内联。

## 验收

- 私聊发图：agent 看到内联图片，附件块里有该图的链接，且标 `"inlined": true`。
- 私聊发 zip：没有内联图片，附件块里有该 zip 的链接，正文里没有 `[文件]` 注记。
- 群里 @ 并带图：agent 直接看到内联图片，附件块同上。
- 群历史里的附件只有链接，没有 `inlined` 字段。
